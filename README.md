# Sistema de Previsão de Demanda de Medicamentos no SUS

## 📋 Sobre o Projeto
Projeto desenvolvido para automatizar e otimizar o planejamento logístico de suprimentos farmacêuticos na saúde pública. O objetivo é utilizar análise estatística e Machine Learning para prever o consumo futuro de medicamentos de alto fluxo, reduzindo o risco de desabastecimento nas unidades de saúde e evitando o desperdício de recursos públicos.

## 🛠️ Tecnologias Utilizadas
- **Python** (Linguagem principal)
- **Pandas** (Manipulação e estruturação de dados)
- **Scikit-Learn** (Modelo preditivo de Regressão Linear)
- **Git & GitHub** (Versionamento de código)

## 📊 Metodologia e Funcionalidades
1. **Análise Estatística Descritiva:** Cálculo de média móvel e desvio padrão do consumo histórico para mensurar a volatilidade da demanda mensal.
2. **Modelo Preditivo:** Aplicação de Regressão Linear para projetar a tendência de consumo para os próximos períodos, auxiliando na tomada de decisão gerencial para novas solicitações de compra e contratos.

## 💡 Impacto de Negócio
Transformação de dados operacionais brutos em *insights* logísticos acionáveis, garantindo previsibilidade e eficiência na assistência farmacêutica.
